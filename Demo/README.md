# همیار خرید فروشگاهی — Frontend Demo

این نسخه یک Frontend برای بررسی سریع سامانه است.

## تکنولوژی
- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage برای نگهداری داده‌های نمونه و نشست کاربر
- بدون Django، دیتابیس یا Backend

## امکانات مشتری
- Register / Login
- جستجوی کالا
- مشاهده اطلاعات کالا، قیمت و موجودی
- جستجوی فروشگاه
- مشاهده اطلاعات فروشگاه و کالاهای آن
- درخواست مسیریابی با Waze و نشان
- نمایش موقعیت فروشگاه به‌صورت پنل اطلاعاتی؛ نقشه مستقل داخل سامانه پیاده‌سازی نشده است.

## امکانات فروشگاه
- ثبت فروشگاه
- ورود به پنل فروشگاه
- افزودن کالا به‌صورت دستی
- مدیریت موجودی
- ویرایش اطلاعات فروشگاه و مختصات
- رابط ورود فایل TXT / CSV / Excel
- رابط تنظیم API برای ارسال موجودی

## اجرای پروژه
فایل `index.html` را مستقیماً در مرورگر باز کنید. برای بهترین نتیجه می‌توانید یک Static Server ساده اجرا کنید:

```bash
python -m http.server 8000
```

سپس:
`http://localhost:8000`

## توجه مهم
این نسخه عمداً فقط Frontend است. فرم‌ها و عملیات در سمت مرورگر با LocalStorage شبیه‌سازی شده‌اند و به Django یا API واقعی متصل نیستند. بخش Excel در این نسخه پذیرش فایل را دارد، اما تبدیل واقعی XLSX به رکوردهای سامانه به کتابخانه یا Backend نیاز دارد.
